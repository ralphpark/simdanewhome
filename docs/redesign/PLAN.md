## 0. 목표와 원칙

- **누가 봐도 애플이 만든 것 같은 사이트.** 쿠퍼티노 디자인 언어(큰 타이포, 넉넉한 여백, 한 화면에 한 메시지, 절제된 색, 스크롤 연출)를 그대로 적용한다.
- 모든 페이지에 모션과 반응형 적용. 로딩 서클까지 로고 액션을 넣을 만큼 디테일을 챙긴다.
- 애플 상표·로고·SF Pro 폰트 파일은 쓰지 않는다(라이선스). 대신 시스템 폰트 스택을 써서, 애플 기기에서는 SF로 보이게 한다.
- 백엔드(API·DB·관리자)는 유지하고, 화면(프론트)만 전부 새로 만든다.

## 2. 페이지 구성

### 2.1 홈
1. **히어로**: 풀스크린 사진(또는 짧은 루프 영상). 카피 "식물과 함께하는 일상의 큐레이션". 스크롤하면 사진이 카드 크기로 줄어들며(scale + radius) 다음 섹션으로 넘어간다.
2. **숫자로 보는 심다** (sticky + 카운트업): 2016년부터 · 프로젝트 100+ · 등록특허 3 · 공식수상 2 · R&D 5억.
3. **PlantBid 플랫폼 하이라이트**: 기기 목업에 simda.me 화면을 넣는다. "동네 화원과 가게가 보내는 선물". 특허(위치 기반 비대면 식물 입찰) 배지와 `simda.me 바로가기 ›`.
4. **서비스 가로 스크롤**: 식물관리 · 교육 · 조경 · 판매 타일(애플 'Get to know' 캐러셀 방식).
5. **대표 작업**: 대표 포트폴리오 3개를 풀블리드로, 스크롤에 맞춰 전환한다.
6. **함께한 곳**: 클라이언트 워드마크 마퀴(캘러웨이 코리아, 신세계, 삼성물산, 아모레퍼시픽, GS칼텍스, 나인원한남, 오페라박물관, 강남성모병원 등. 로고 이미지 없이 텍스트로).
7. **매거진 최신 3편**
8. **마무리 CTA**: 프로젝트 문의(B2B) / 예약상담

### 2.2 브랜드 스토리 (이력서 기반)
1. 오프닝: "국내 1호 식물 큐레이터" 이주연 대표. 큰 인물 사진과 한 문장.
2. 철학: 심다 = 심고 + 초심. "풀의 마음과 처음의 마음".
3. **스크롤 타임라인** (스크롤에 맞춰 연도가 넘어가는 sticky 연출):
   - 2016 심다 시작(도소매)
   - 2017–19 서울정원박람회 메인 무대 '정원', 대한민국 한평정원 우수상(순천시장상)
   - 2020 KBS 아침1라디오 '나의 작은 식물원', 와디즈 식물 생활 키트 2,371% 펀딩
   - 2021 (주)에스아이엠지오 법인 설립, 여성기업 인증
   - 2022 기업부설연구소 설립, 특허 등록(AI 식물 정보 큐레이션)
   - 2023 오브젝트 바이 프라이즈 '베스트 스페이스', 신용보증기금 스텝업 R&D 5억
   - 2024 벤처기업 인증, AI 식물 큐레이션 MVP
   - 2025 특허 2건(생성형 AI 대화형 추천, 위치 기반 비대면 입찰 플랫폼)
   - 2023–2026 한국농업기술진흥원 벤처육성기업 4년 연속
4. 인증·특허·수상 카드(벤토 그리드)
5. 미디어: KBS, 브리크매거진, 문체부 '공감', 천재교육 등
6. 연혁 데이터는 기존 timelines DB로 관리한다(관리자 화면 유지). 이력서 기준으로 내용을 갱신한다.

### 2.3 서비스
애플 제품 페이지 패턴: 왼쪽 sticky 이미지, 오른쪽 스크롤 텍스트. 섹션마다 대표 사례와 CTA.
1. **PlantBid 플랫폼 (simda.me)**: 가장 먼저 보여준다. 동네 화원 선물 중개, 근처 판매자가 직접 배송, 특허 기술.
2. **식물관리**: 정기 유지관리(캘러웨이 코리아, 강남성모병원, 마이리얼트립, 헤이즈밀 베이커리 등 진행 중)
3. **교육**: 기업·기관·학교 워크숍(신세계 아카데미, GS칼텍스 440명, HSBC, 서울시평생교육진흥원 등)
4. **조경**: 정원 디자인·시공(나인원한남, 닥터스피부과, 오페라박물관, 삼덕유화 송도 골프빌라 등)
5. **판매**: 플랜트 연출·판매. 온라인샵(simda.me)으로 연결
- 기존 AI 식물 상담(챗) 페이지는 서비스 안 'AI 큐레이션' 링크로 유지한다(특허 기반 기능).

### 2.4 포트폴리오 ("이 팀과 작업하고 싶다"가 목표)
1. 상단 풀스크린 대표작. 스크롤하면 커버가 줄어들며 그리드가 등장한다.
2. 카테고리 세그먼트 컨트롤: 전체 · 정원 · 조경 · 플랜트 · 연출 · 교육 · 기획
3. 벤토/메이슨리 그리드. 호버하면 이미지가 천천히 확대되고 제목이 올라온다. 필터를 바꾸면 레이아웃 애니메이션(layout transition).
4. 상세: 커버 패럴랙스, 이미지 시퀀스, 메타(연도·장소·분류), 다음 프로젝트로 넘기기
5. **아카이브 인덱스**: 2017–2026 프로젝트 100+를 연도별 리스트로 보여준다(사진 없는 프로젝트도 노출해 규모와 신뢰를 보여줌). 데이터는 이력서에서 `client/src/content/projects.ts`로 옮긴다.

### 2.5 매거진
- 피처 기사 히어로. 커버 이미지 확대와 타이틀 마스크 리빌.
- 카테고리 탭, 카드 스태거 등장, 호버 모션
- 상세: 상단 읽기 진행 바, 본문 이미지 페이드업, 관련 글
- 글 작성은 기존 관리자(tiptap) 그대로

### 2.6 고객센터
- `/support`: 자주 묻는 질문(아코디언), 연락처·운영시간, 채널톡, 하위 메뉴 카드(B2B 협업 / 예약상담)
- `/support/b2b`: 협업 제안 폼(기존 API 유지). 협업 분야 소개를 추가하고 회사소개서 다운로드는 삭제
- `/support/booking`: 자체 예약 폼(네이버예약 중단으로 결정). 기존 `POST /api/bookings`와 bookings 테이블을 그대로 쓰고, 관리자 화면의 예약 목록에서 확인한다.
  - 애플식 단계형 폼: ① 상담 유형(식물관리·교육·조경·판매·기타) → ② 희망 날짜·시간(달력 + 시간 칩) → ③ 이름·연락처·메시지 → ④ 확인 → 완료 화면(체크 애니메이션)
  - 단계 전환은 슬라이드 모션, 진행 표시 점, 입력 검증은 실시간(기존 zod 스키마)
  - 예약 알림 메일은 SMTP 설정이 있어야 발송된다(현재 미설정, 별도 결정)

### 2.7 공통
- **GNB**: 반투명 블러 바(frosted glass). 스크롤하면 얇아지고, 모바일에서는 풀스크린 메뉴(애플식 펼침 애니메이션)
- **푸터**: 애플식 링크 묶음, 사업자 정보, 저작권
- **로딩**: 잎 심볼 SVG 선 그리기(stroke-dashoffset) → 채움 → `simda` 워드마크 페이드. 첫 진입 시 1회. 페이지 전환은 짧은 크로스페이드
- **반응형 브레이크포인트**(애플 기준): 734 / 1068 / 1440
- **접근성**: `prefers-reduced-motion`이면 모션 최소화, 키보드 포커스 링, 대비 4.5:1 이상
- **성능**: 모션은 transform/opacity만 사용. 이미지는 lazy 로딩, 적절한 크기, 60fps 유지

## 4. 기술 방식
- 기존 React + Vite + wouter + Tailwind + framer-motion을 유지한다. 새 의존성은 Lenis(스무스 스크롤) 하나만 추가
- 공통 컴포넌트는 `client/src/components/site/`, 디자인 토큰은 `client/src/styles/tokens.css`
- 고정 콘텐츠(카피, 서비스, 아카이브, FAQ)는 `client/src/content/*.ts`. 관리자가 바꿔야 하는 것(포트폴리오, 매거진, 연혁)만 DB 사용
- 작업 브랜치 `redesign` → Vercel 프리뷰 주소에서 확인 → 승인 후 main(simda.kr) 반영

## 7. 사이트 이미지 교체 기능 (관리자)
- 테이블 `site_images` (key PK, url, alt, updated_at)
- API: `GET /api/site-images`(공개), `PUT /api/site-images/:key`(관리자), `POST /api/blob-upload`(관리자, Vercel Blob 브라우저 직접 업로드 토큰 발급. 4.5MB 한도 회피)
- 프론트: `useSiteImage(key)` → DB 값이 있으면 그것, 없으면 `client/src/content/images.ts`의 Unsplash 기본값
- 관리자 '사이트 이미지' 탭: 키별 미리보기, 파일 업로드로 교체, 기본값으로 되돌리기
- 키 목록: `home.hero`, `home.platform`, `home.cta`, `story.opening`, `story.philosophy`, `services.platform`, `services.care`, `services.education`, `services.landscape`, `services.sales`, `support.hero`, `b2b.hero`, `booking.hero`, `portfolio.hero`, `magazine.hero`
