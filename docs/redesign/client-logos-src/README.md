# 홈 고객사 로고 원본과 단색 PNG 생성

사용자가 제공한 기존 원본 34개와 신규 원본 6개를 보존한다. 오페라박물관 스크린샷은 그대로 두고 별도의 합성 PNG를 만들어, 총 40곳의 로고를 변환한다. 이 폴더는 Vite의 public 폴더 밖에 있어 배포 이미지에 포함되지 않는다. `logos.json`에는 이름, 서비스 목록 순서, 변환 방식과 입력 파일 SHA-256을 기록했다.

저장소 루트에서 실행:

```sh
node docs/redesign/client-logos-src/bake.mjs
```

로컬 헤드리스 Chrome 실행 권한이 필요하다. 기존 검수용 `browser.mjs`를 사용하며 환경 파일, API 서버, 외부 네트워크를 사용하지 않는다. 추가 의존성도 없다.

- Chrome canvas에 긴 변 1200px로 원본을 그린다.
- 기본 alpha는 `원래 alpha × clamp((255 - min(r,g,b)) / 40, 0, 1)`이다. 컴패션·신용보증기금은 원래 alpha를 사용한다.
- 신규 흰 배경 래스터 5개는 `knockout-clean`을 사용한다. 위 식의 255를 235로 바꾸어 압축 과정의 옅은 회색 얼룩을 제거한다. 넥서스·스타일난다·서울시민대학·오페라박물관·피스피스에만 적용하며, 투명 배경의 새싹은 기존 `knockout`을 사용한다. 색 로고의 심볼과 내부 여백, 피스피스의 가는 선을 변환 시트에서 확인했다.
- 잉크 범위를 자르고 최종 여백 1px, 최대 높이 156px로 축소한다.
- RGB `#1d1d1f`와 canvas의 256단계 alpha를 손실 없이 팔레트 PNG로 저장한다. CSS filter는 사용하지 않는다.
- 표시 면적 기준은 4800px². 면적에 `clamp((밀도 중앙값 / 해당 로고 밀도)^0.35, 0.75, 1.15)`를 곱해 무거운 로고는 줄이고 가벼운 로고는 키운다. 기존 너비 최대 200px, 높이 24~52px 제한은 유지하고 `object-fit: contain`으로 원래 비율을 보존한다.
- `client/src/content/clientLogos.ts`의 크기와 20개씩 두 줄을 생성한다. `brand.ts`의 `clients` 순서를 그대로 따른다. 모바일 크기는 0.6배다.
- 두 반복 그룹에 마지막 간격까지 동일하게 포함한다. 간격은 데스크톱 68px / 모바일 32px, 속도는 두 줄 모두 40px/s다. 원본 순서는 각 줄의 그룹 내부에서 유지하고 둘째 줄은 반대 방향으로 움직인다.

출력:

- `client/public/images/clients/*.png`: 사이트용 단색 PNG 40개, 총 504,067바이트. 기존 34개는 447,610바이트로 개별 SHA-256까지 동일하고, 신규 6개는 56,457바이트다.
- `client/src/content/clientLogos.ts`: 한국어 alt, 이미지 경로, 사전 계산한 표시 크기, 줄별 이동 시간.
- `docs/redesign/verification/logos/mono-sheet.png`: 단색 로고와 실제 크기 모아 보기.
- `docs/redesign/verification/logos/bake-report.json`: 크기·비율·밀도·면적 보정 기록.

검수 결과: HSBC, 캐리어, 현대백화점 등의 내부 흰 글자·빈 공간 유지. 서울특별시는 사용자 제공 공식 가로형(심벌 + 서울특별시 글자) 원본 `seoul.png`로 교체했고 knockout 방식으로 변환했다. 나머지 로고도 원본 형상과 워드마크를 유지한다.

법무법인 넥서스·청년사관학교·스타일난다·서울시민대학·오페라박물관·피스피스를 포함한 40곳 모두 홈 로고 흐름과 서비스 '함께한 곳'에 연결했다. 홈에서 새싹의 이름은 '청년취업사관학교 새싹'이다. 서비스는 기존 목록 이름을 유지하며 현재 로고 40개, 글자 전용 칸 0개다. 로고가 없을 때 글자를 표시하는 fallback은 유지한다.

## 오페라박물관 합성

`opera-museum-source.webp`(2000×1904)를 Chrome canvas로 열고 주변 선·메뉴·경계를 제외한 범위에서 잉크 경계를 찾았다. 좌표는 원본의 왼쪽 위가 (0, 0)이며, 아래 범위는 끝점을 포함한다.

- 글자 로고: x=137~288, y=233~290 → 152×58px.
- OM 심볼: x=137~229, y=1564~1702 → 93×139px.
- 심볼을 39×58px로 비율 유지 축소하고, 오른쪽에 152×58px 글자를 배치했다. 두 요소의 전체 높이는 58px이며 세로 중앙을 맞췄다. 간격은 17px(58×0.3 반올림)이다.
- 바깥 여백은 사방 4px, 흰 바탕의 결과는 216×66px다. 결과 파일은 `opera-museum.png`이며, 이후 단색 변환에서 흰 바탕을 투명 처리한다.
- 일회용 합성 스크립트는 `/tmp/simda-six-logos/compose-opera.mjs`, 미리보기와 자른 이미지도 같은 임시 폴더에 둔다. 저장소에 일회용 스크립트나 의존성을 추가하지 않았다.

## 신규 6곳 표시 크기

아래는 홈·서비스가 공유하는 데스크톱 표시 상자다. `object-fit: contain`으로 비율을 유지하며 모바일은 가로·세로 모두 0.6배다. 전체 40개 밀도 중앙값을 다시 계산하므로 기존 로고 일부의 표시 상자도 1px 조정되지만 기존 PNG 바이트는 변하지 않는다.

| 이름 | mode | 데스크톱 | 모바일 |
| --- | --- | --- | --- |
| 법무법인 넥서스 | knockout-clean | 120×36px | 72×21.6px |
| 청년취업사관학교 새싹 | knockout | 112×49px | 67.2×29.4px |
| 스타일난다 | knockout-clean | 78×49px | 46.8×29.4px |
| 서울시민대학 | knockout-clean | 100×48px | 60×28.8px |
| 오페라박물관 | knockout-clean | 119×34px | 71.4×20.4px |
| 피스피스 | knockout-clean | 114×49px | 68.4×29.4px |

넥서스(224×84)와 오페라박물관의 글자 추출본(152×58)은 원본 해상도가 낮고, 피스피스는 원본부터 가는 필기체다. 현재 표시 크기에 맞춰 검수하며, 고해상도 원본을 확보하면 같은 파이프라인에서 교체할 수 있다.

검증: `npm run check`, `npm run build`, `node --import tsx script/assert-service-logos.mjs` 통과. 오프라인 Chrome에서 서비스 1440·1068·390px의 로고 40개 로드, 글자 전용 칸 0개, 정렬·넘침 없음과 브라우저 예외 0개를 확인했다. 홈 1440px은 20개씩 두 줄, 반복 그룹 동일 너비, 68px 간격, 양방향 40px/s를 검증했다. 최종 단색 시트와 서비스 1440·390px, 홈 신규 로고 장면 3장을 직접 열어 확인했으며 스크린샷은 `/tmp/simda-six-logos/`에 있다.
