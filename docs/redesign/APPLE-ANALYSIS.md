# 애플 홈페이지 재분석 (2026-11-05, apple.com/kr 실측)

측정 환경: 1440×900, apple.com/kr 홈과 iPhone Duo 제품 페이지(흰 바탕 제품 페이지).

## 1. 바탕과 색
- 바탕은 흰색(#fff). 구간 구분은 연회색 `#f5f5f7` 섹션을 번갈아 둔다. 맨 아래 목록은 `#fafafc`.
- 글자 `#1d1d1f`, 보조 글자 `#6e6e73`·`#86868b`.
- 검정 섹션은 제품이 어두울 때만 쓴다. 흰 제품 페이지는 거의 전부 흰색과 연회색이다.
- 주 버튼은 파란 알약(#0071e3, 높이 44, 글자 17, 안쪽 여백 11×21, 모서리 980). 보조는 같은 모양의 테두리 버튼. 둘을 17px 간격으로 나란히 둔다.

## 3. 배치
- 홈: 화면 폭 전체 타일. 위에 글(제목·한 줄·버튼 두 개)을 가운데 두고, 아래를 사진이 채운다. 타일 사이 간격 12px, 모서리 없음. 아래쪽은 2열 타일(높이 580).
- 제품 페이지: 섹션 위아래 여백 128~144px. 순서는 눈썹 → 80px 제목 → 21px 소개 문단 → 큰 사진·영상.
- 하이라이트 갤러리: 48px 제목을 왼쪽에 둔다. 둥근 카드(모서리 28, 연회색)가 가로로 이어지고 다음 카드가 살짝 보인다. 카드 위쪽 가운데 28px 문구, 아래 미디어, 그 밑에 점 표시와 재생 버튼.
- 사양 구간: 왼쪽은 소개 문단, 오른쪽은 40px 수치와 작은 회색 설명 목록.
- 페이지 아래에 떠 있는 반투명 알약 바(가격 + 구입하기)가 스크롤을 따라다닌다(리퀴드 글래스).
- 로컬 내비: 제품 이름 왼쪽, 오른쪽 작은 파란 '구입하기' 알약, 반투명 흰 유리.

## 4. 모션
- 글: 화면에 들어올 때 아래에서 살짝 떠오르며 나타난다. 여러 줄이면 시차를 둔다.
- 사진·영상: 작게 시작해 화면 전체로 커지거나(몰입형), 크게 시작해 제자리로 줄어든다. 스크롤과 묶여 있다.
- 갤러리: 카드가 가로로 넘어가고 점 표시가 진행을 보여 준다.
- 장식용 그래픽 애니메이션은 거의 없다. 움직임은 제품(우리에겐 사진과 앱 화면)에 붙어 있다.

## 5. 애플 디자인 원칙(쿠퍼티노, 2025~ 리퀴드 글래스)
- 위계: 가장 중요한 것 하나를 크게. 나머지는 물러선다.
- 조화: 둥근 모서리, 반투명 유리 재질, 하드웨어와 맞는 곡률.
- 일관성: 같은 역할은 같은 모양.
- 콘텐츠가 주인공이고, 인터페이스는 반투명하게 뒤로 물러난다.

## 6. 심다에 옮기는 방법
- 흰 바탕과 `#f5f5f7` 구간을 번갈아 쓰고, 검정 섹션은 쓰지 않는다.
- 파란 버튼 자리에 심다 그린 `#03473e` 알약을 쓰고, 보조 버튼은 테두리 알약으로 한다.
- 사진이 주인공이다. 첫 화면 사진 확장, 하이라이트 갤러리, 몰입형 사진, 작업 타일에 쓴다.
- simda 플랫폼은 흰 바탕 가운데 아이폰을 두고, 화면 속 앱이 단계별로 바뀌게 한다(애플 기기 소개 방식).
- 아래쪽에 반투명 알약 바 "큐레이터와 상담하기 | 예약상담"을 띄운다.
- 글자 크기는 2장의 표를 그대로 따른다.
