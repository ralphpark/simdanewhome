3. 관리자 페이지 (Admin Dashboard) ⭐ 중요
3.1 관리자 로그인 (/admin/login)
인증 시스템
* 이메일 + 비밀번호 로그인
* JWT 또는 세션 기반 인증
* 로그인 실패 시 에러 메시지
* 비밀번호 찾기 기능 (선택사항)
* 로그인 시도 제한 (보안)
3.2 관리자 대시보드 메인 (/admin/dashboard)
대시보드 개요
* 주요 지표 카드:
    * 이번 주 새 예약/상담 건수
    * 처리 대기 중인 예약 건수
    * 새 기업 제안 건수
    * 이번 달 포트폴리오 조회수
    * 매거진 포스트 수
    * 총 챗봇 대화 수 (선택사항)
차트 및 통계 (선택사항)
* 월별 예약 추이 그래프 (Line Chart)
* 상담 유형별 분포 차트 (Pie Chart)
* 최근 활동 타임라인
빠른 링크
* "새 예약 확인하기" → /admin/bookings
* "기업 제안 확인하기" → /admin/b2b-proposals
* "포트폴리오 추가" → /admin/portfolios/new
* "매거진 작성" → /admin/posts/new
3.3 예약/상담 관리 페이지 (/admin/bookings) ⭐ 핵심 기능
예약 목록 테이블
* 컬럼: ID, 이름, 연락처, 이메일, 상담 유형, 희망 날짜/시간, 상태, 제출일
* 정렬 기능 (날짜순, 상태별, 이름순)
* 검색 기능 (이름, 이메일, 연락처)
* 필터:
    * 상태별: 대기 중 / 확인 완료 / 상담 완료 / 취소
    * 상담 유형별: AI 큐레이션 / 구독 관리 / 교육 / 기업 협업 / 기타
    * 날짜 범위: 오늘, 이번 주, 이번 달, 전체
* 페이지네이션 (10개, 20개, 50개씩 선택 가능)
* 엑셀 내보내기 기능 (선택사항)
예약 상세 보기
* 행 클릭 시 모달 또는 상세 페이지 표시
* 모든 예약 정보 표시:
    * 고객 정보: 이름, 연락처, 이메일
    * 상담 유형
    * 희망 날짜 및 시간
    * 문의 내용 전체 표시 (고객이 Textarea에 작성한 모든 내용)
    * 제출 일시
    * 현재 상태
    * 관리자 메모 (관리자 전용 필드)
예약 상태 관리
* 상태 변경 드롭다운:
    * 대기 중 (pending) - 기본값
    * 확인 완료 (confirmed) - 고객에게 확인 연락 완료
    * 상담 완료 (completed) - 상담 진행 완료
    * 취소 (cancelled) - 고객 요청 또는 기타 사유로 취소
* 상태 변경 시 자동으로 데이터베이스 업데이트
* 상태 변경 히스토리 기록 (선택사항)
* 상태별 색상 구분 (pending: 노란색, confirmed: 파란색, completed: 녹색, cancelled: 회색)
액션 버튼
* "상담 메모 추가/수정" - 관리자 전용 메모 작성 (고객은 볼 수 없음)
* "고객에게 이메일 보내기" (선택사항)
* "예약 삭제" - 확인 후 완전 삭제
일괄 처리 기능 (선택사항)
* 여러 예약 선택하여 일괄 상태 변경
* 일괄 삭제
3.4 기업 제안 관리 페이지 (/admin/b2b-proposals) ⭐ 핵심 기능
기업 제안 목록 테이블
* 컬럼: ID, 회사명, 담당자명, 연락처, 이메일, 상태, 제출일
* 정렬 기능 (날짜순, 회사명순, 상태별)
* 검색 기능 (회사명, 담당자명, 이메일)
* 필터:
    * 상태별: 대기 중 / 검토 중 / 연락 완료 / 협업 진행 / 보류
    * 날짜 범위: 오늘, 이번 주, 이번 달, 전체
* 페이지네이션
* 엑셀 내보내기 기능 (선택사항)
제안 상세 보기
* 모든 제안 정보 표시:
    * 기업 정보: 회사명, 담당자명
    * 연락처, 이메일
    * 사업 분야 (있는 경우)
    * 제안 내용 전체 표시 (고객이 작성한 모든 내용)
    * 첨부 파일 다운로드 링크 (있는 경우)
    * 제출 일시
    * 현재 상태
    * 관리자 검토 메모
제안 상태 관리
* 상태 변경 드롭다운:
    * 대기 중 (pending)
    * 검토 중 (reviewing)
    * 연락 완료 (contacted)
    * 협업 진행 (in_progress)
    * 협업 완료 (completed)
    * 보류 (on_hold)
* 관리자 메모 추가/수정 기능
* 상태별 색상 구분
액션 버튼
* "제안 검토 메모 추가"
* "기업에게 이메일 보내기"
* "제안 삭제"
3.5 포트폴리오 관리 (/admin/portfolios)
포트폴리오 목록
* 그리드 뷰 또는 테이블 뷰 전환 가능
* 각 항목: 썸네일, 제목, 클라이언트명, 날짜, 공개 여부, 조회수
* "새 포트폴리오 추가" 버튼 (상단 우측)
* 검색 및 필터링 (카테고리, 공개 여부, 날짜)
* 드래그 앤 드롭으로 순서 변경 (선택사항)
포트폴리오 추가/수정 폼
* 제목 (필수, 100자 제한)
* 설명 (Textarea, 2000자 제한)
* 이미지 업로드:
    * 멀티플 이미지 업로드 (최대 20장)
    * 드래그 앤 드롭 지원
    * 이미지 미리보기
    * 이미지 순서 변경
    * 대표 이미지 선택
* 클라이언트명 (100자 제한)
* 프로젝트 날짜 (Date Picker)
* 카테고리 (드롭다운: 주거공간, 상업공간, 오피스, 조경, 기타)
* 공개/비공개 토글
* "저장" 및 "저장 후 공개" 버튼
이미지 최적화
* 자동 리사이징 (최대 1920px)
* WebP 변환 (선택사항)
* Cloudinary 또는 AWS S3에 저장
3.6 매거진 포스트 관리 (/admin/posts)
포스트 목록
* 테이블 뷰: 썸네일, 제목, 작성자, 카테고리, 태그, 공개 여부, 조회수, 작성일
* "새 포스트 작성" 버튼 (상단 우측)
* 검색 (제목, 내용)
* 필터 (카테고리, 공개 여부, 작성자)
* 정렬 (최신순, 조회수순, 제목순)
포스트 작성/수정 에디터
* 제목 (필수, 200자 제한)
* Slug (URL용):
    * 자동 생성 (제목 기반)
    * 수동 수정 가능
    * 중복 확인
* 리치 텍스트 에디터:
    * Quill, TinyMCE, 또는 Markdown 에디터
    * 텍스트 포맷팅 (굵게, 기울임, 밑줄, 제목, 리스트)
    * 이미지 삽입 (드래그 앤 드롭 또는 업로드)
    * 링크 삽입
    * 코드 블록 (선택사항)
* 썸네일 이미지 업로드:
    * 드래그 앤 드롭
    * 권장 비율 안내 (16:9)
    * 이미지 크롭 기능 (선택사항)
* 작성자 (자동 입력 또는 선택)
* 카테고리 선택 (드롭다운 또는 새 카테고리 추가)
* 태그 입력:
    * 멀티플 태그
    * 자동완성 기능
    * 쉼표 또는 엔터로 구분
* 발행 상태:
    * 공개/비공개 토글
    * 예약 게시 (날짜/시간 선택, 선택사항)
* SEO 설정 (접을 수 있는 섹션):
    * Meta Title (60자 제한)
    * Meta Description (160자 제한)
    * OG 이미지 (썸네일과 별도)
* "미리보기" 버튼 - 새 탭에서 포스트 미리보기
* "임시저장" 버튼 - 공개하지 않고 저장
* "저장" 버튼 - 현재 상태로 저장
* "게시" 버튼 - 공개 상태로 저장 및 발행
3.7 관리자 네비게이션
사이드바 메뉴
* 대시보드 (홈 아이콘)
* 예약/상담 관리 (뱃지: 새 예약 건수 표시)
* 기업 제안 관리 (뱃지: 새 제안 건수 표시)
* 포트폴리오 관리
* 매거진 관리
* 챗봇 대화 기록 (선택사항)
* 사이트 설정 (선택사항)
* 로그아웃
상단 헤더
* 좌측: 사이트명 "심다 Admin"
* 우측:
    * 알림 아이콘 (새 예약/제안 알림, 클릭 시 드롭다운)
    * 관리자 프로필 드롭다운 (이메일, 로그아웃)
    * "사이트 보기" 링크 (메인 홈페이지로 이동, 새 탭)
반응형 디자인
* 모바일에서는 사이드바를 햄버거 메뉴로 변경
* 테이블은 카드 형태로 변환
