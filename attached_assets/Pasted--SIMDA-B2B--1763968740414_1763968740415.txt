프로젝트 개요
식물 브랜드 "심다(SIMDA)"의 공식 홈페이지를 구축합니다. 서비스 소개, 예약/상담, 포트폴리오, 콘텐츠 발행, B2B 협업 제안 등 브랜드 운영 전반을 통합하는 반응형 웹사이트입니다.
기술 스택
* 프론트엔드: React.js (Next.js 권장) 또는 Vue.js
* 백엔드: Node.js + Express.js
* 데이터베이스: PostgreSQL 또는 MongoDB
* 스타일링: Tailwind CSS 또는 styled-components
* 폼 관리: React Hook Form + Zod validation
* 이미지 최적화: Next.js Image 컴포넌트 또는 Cloudinary 연동
* SEO: Next.js의 Metadata API 또는 React Helmet
* AI 챗봇: Google Gemini API
* 외부 연동: 채널톡 SDK, 파일 다운로드 기능

    * 24시간 이내 입찰 마감
4. ✅ 최적 선택
    * 가격, 거리, 평점, 리뷰 비교
    * 원하는 판매자 선택 및 구매

* 🚚 배송/픽업 선택 - 편한 방법으로

FAQ 예시
* Q: 온라인샵과 지역 기반 샵의 차이점은 무엇인가요?
* A: 온라인샵(simgo.kr)은 전국 어디서나 주문 가능한 공식 쇼핑몰이며, 지역 기반 샵(simda.me)은 내 주변 공급자와 직거래할 수 있는 마켓플레이스입니다.
* Q: 배송은 얼마나 걸리나요?
* A: 온라인샵은 2-3일, 지역 기반 샵은 공급자와 협의하여 결정됩니다.
* Q: 결제 방법은 어떻게 되나요?

CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email VARCHAR(255) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL,

6. API 엔드포인트 설계
인증
* POST /api/admin/login - 관리자 로그인 (이메일, 비밀번호)
* POST /api/admin/logout - 로그아웃
* GET /api/admin/me - 현재 로그인한 관리자 정보
예약/상담
* POST /api/bookings - 새 예약 생성 (공개)
* GET /api/admin/bookings - 모든 예약 조회 (관리자 전용)
    * 쿼리: ?page=1&limit=10&status=pending&search=홍길동&sort=created_at_desc
* GET /api/admin/bookings/:id - 예약 상세 조회 (관리자)
* PUT /api/admin/bookings/:id - 예약 상태 및 메모 업데이트 (관리자)
* DELETE /api/admin/bookings/:id - 예약 삭제 (관리자)
기업 제안
* POST /api/b2b - 새 기업 제안 제출 (공개)
* GET /api/admin/b2b - 모든 제안 조회 (관리자 전용)
    * 쿼리: ?page=1&limit=10&status=pending&search=회사명
* GET /api/admin/b2b/:id - 제안 상세 조회 (관리자)
* PUT /api/admin/b2b/:id - 제안 상태 및 메모 업데이트 (관리자)
* DELETE /api/admin/b2b/:id - 제안 삭제 (관리자)
포트폴리오
* GET /api/portfolios - 포트폴리오 목록 (공개된 것만)
    * 쿼리: ?category=주거공간&page=1&limit=12
* GET /api/portfolios/:id - 포트폴리오 상세 (조회수 증가)
* GET /api/admin/portfolios - 모든 포트폴리오 (관리자)
* POST /api/admin/portfolios - 새 포트폴리오 생성 (관리자)
* PUT /api/admin/portfolios/:id - 포트폴리오 수정 (관리자)
* DELETE /api/admin/portfolios/:id - 포트폴리오 삭제 (관리자)
* PUT /api/admin/portfolios/reorder - 순서 변경 (관리자, 선택사항)
매거진/블로그
* GET /api/posts - 포스트 목록 (공개된 것만)
    * 쿼리: ?page=1&limit=12&category=관리팁&tag=다육식물
* GET /api/posts/:slug - 포스트 상세 (slug로 조회, 조회수 증가)
* GET /api/admin/posts - 모든 포스트 (관리자)
* POST /api/admin/posts - 새 포스트 생성 (관리자)
* PUT /api/admin/posts/:id - 포스트 수정 (관리자)
* DELETE /api/admin/posts/:id - 포스트 삭제 (관리자)
AI 챗봇
* POST /api/chatbot - 챗봇 메시지 전송 및 AI 응답 받기
    * Request Body: { message: string, conversationHistory: array, sessionId?: string }
    * Response: { response: string, conversationId: string }
파일 업로드
* POST /api/upload - 이미지 업로드 (공개 또는 관리자)
    * Multipart form-data
    * Response: { url: string, filename: string }
* POST /api/upload/multiple - 여러 이미지 업로드
    * Response: { urls: array }
대시보드 통계
* GET /api/admin/dashboard/stats - 대시보드 주요 지표 (관리자)
    * Response: 새 예약 건수, 대기 중인 예약, 새 제안, 포트폴리오 수, 포스트 수 등
기타
* GET /api/categories - 카테고리 목록 (공개)
* GET /api/tags - 인기 태그 목록 (공개, 선택사항)
* GET /sitemap.xml - 사이트맵 (자동 생성)
* GET /robots.txt - robots.txt
